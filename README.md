# Jiyoung Baek — Personal Website

Static site, no build step. Designed as a magazine you flip through page by
page: a two-page spread on desktop, one page at a time on phones. Turn pages
with the arrow keys, the on-screen arrows, swiping, or clicking a page.
Figures are generative SVGs drawn in the browser (a bit different each visit).

## Edit content

Everything lives in `index.html`, inside `<div class="pages-src">`. Each
`<section class="page">` is one magazine page; their order is the page order.
Keep an **even** number of pages so the back cover lands on its own.

- **Letter** (`#letter`) — your bio.
- **Research** (`#css`, `#inequality`, `#urban-ai`, `#regional`) — one page each.
- **Publications** (`#publications`) — replace each `.pub` with real papers.
- **Correspondence** (`#contact`) — replace `href="#"` links (Scholar,
  LinkedIn, X, CV). Drop your CV into `assets/` and link `assets/cv.pdf`.

Page numbers, running heads, the contents page numbers and the bottom scrubber
are all generated by `script.js`, so adding/reordering pages needs no other
changes. Link to any page with `data-goto="<page id>"`; deep links work as
`#p5` or `#inequality`.

After changing `style.css` or `script.js`, bump the `?v=` number on their
links in `index.html` so returning visitors (especially on phones) don't keep
an old cached copy.

Colors and fonts are in `style.css` under `:root` (`--accent` is the single
accent color).

## Preview locally

```bash
cd ~/Documents/jiyoung-baek-website
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy for free (GitHub Pages)

```bash
cd ~/Documents/jiyoung-baek-website
git init
git add .
git commit -m "Initial site"
gh repo create jiyoung-baek.github.io --public --source=. --push
```

Then enable GitHub Pages in the repo settings (Settings → Pages → branch
`main`, root). If you name the repo `<username>.github.io`, the site is
served directly at `https://<username>.github.io`.

Alternatively, drag the folder into [Netlify Drop](https://app.netlify.com/drop)
for an instant URL, then connect a custom domain later.
